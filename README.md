# netflix-data-analysis
# Netflix Titles Exploratory Data Analysis (EDA)

## 🎯 Project Overview
This project explores the Netflix titles dataset (8,800+ records) to uncover trends in content growth, movie vs. TV show ratios, top producing countries, and common genres[cite: 2]. Completed as part of my data analytics training at ReDI School.

## 🛠️ Tools & Libraries Used
* **Python**
* **Pandas & NumPy** (Data cleaning and preprocessing)[cite: 2]
* **Matplotlib & Seaborn** (Data visualization)[cite: 2]

## 🔍 Key Insights & Findings
* **Content Split:** Approximately 69.7% of Netflix titles are Movies, while 30.3% are TV Shows[cite: 2].
* **Top Producing Countries:** The United States (3,680 titles) and India (1,046 titles) lead the platform significantly[cite: 2].
* **Growth Peak:** Content additions peaked sharply between 2018 and 2020, with 2019 recording the highest volume[cite: 2].
* **Average Duration:** The average movie length is 100 minutes, and the average TV show runs for 1.8 seasons[cite: 2].
